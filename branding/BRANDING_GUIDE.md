# ECUAVISA UIO - BRANDING DIGITAL

## Objetivo

Definir una identidad visual reusable para aplicaciones internas
desarrolladas por Ecuavisa UIO.

Este branding debe aplicarse a:

- Web Apps
- Dashboards tecnicos
- PWA
- Herramientas operativas
- Aplicaciones Android/iOS cuando corresponda

La identidad visual debe ser consistente sin convertir todas las
aplicaciones en copias exactas entre si.

# Principios UI

- Dark mode como apariencia principal
- Interfaces compactas
- Bordes sutiles
- Cards redondeadas
- Espaciado moderado
- Responsive
- Tipografia system-ui / Inter
- Azul corporativo para acciones principales
- Verde para estados OK / Online
- Rojo solamente para acciones destructivas
- Evitar elementos excesivamente grandes
- Priorizar legibilidad tecnica

---

# Header

Debe contener:

- Logo institucional
- Nombre de aplicacion
- Ubicacion o unidad cuando aplique
- Descripcion corta del servicio
- Estado general opcional

Ejemplo:

    WireGuardVPN — Ecuavisa UIO
    Concentrador VPN Broadcast · videosrv

---

# Footer

Texto institucional:

    Derechos de autor © 2025. Ecuavisa UIO.
    Contáctanos: valtamirano@ecuavisa.com

Puede incluir:

- nombre de aplicacion
- version
- estado del servicio
- host

---

# Splash Screen

La splash screen debe:

- utilizar logo blanco
- fondo oscuro
- mostrar nombre de aplicacion
- mostrar Ecuavisa UIO
- desaparecer automaticamente al cargar

Duracion recomendada:

    500 - 1200 ms

No debe bloquear innecesariamente la operacion.

---

# Estados

Online / OK:

    verde

Offline:

    gris

Warning:

    amarillo

Error / Revoked:

    rojo

---

# Responsive

La interfaz debe funcionar en:

- Desktop
- Laptop
- Tablet
- Movil

En pantallas pequeñas:

- reducir padding
- convertir tablas grandes en bloques o scroll horizontal
- evitar botones excesivamente grandes
- mantener controles tactiles usables

---

# Reutilizacion

Para aplicar este branding en otro proyecto:

Compartir:

    BRANDING_GUIDE.md
    logo-white.png
    logo-blue.png
    ecuavisa-theme.css

Instruccion sugerida:

    "Aplica el Branding Digital Ecuavisa UIO definido en estos archivos.
    Conserva la funcionalidad y adapta el sistema visual al proposito
    de esta aplicacion."
